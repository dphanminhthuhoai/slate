# dmath Slate

Bảng viết dạy Toán của thầy Phan Minh Duy (dmath). Mở trang web của kho này trên iPad, bấm Chia sẻ → "Thêm vào Màn hình chính" để dùng như một app.

- `index.html`: toàn bộ app (một tệp).
- `sw.js`: lưu sẵn app trong máy để mở được khi không có mạng.
- `manifest.webmanifest`, `icon-*.png`: tên và biểu tượng trên màn hình chính.
